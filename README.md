# Swiggy-Project-SQL-
* Analyzed food delivery data using SQL to identify revenue, orders, and customer trends. * Used JOINs, CTEs, aggregations, and window functions to generate business insights. * Performed restaurant, city, cuisine, pricing, and customer analysis to support decisions.


Now I am Going To Explain This Project Using STAR Methods :)

⭐ S — Situation

“I worked on a Swiggy food delivery dataset containing information about restaurants, locations, dishes, categories, prices, ratings, and order dates.”

⭐ T — Task

“My goal was to clean and validate the data, structure it properly, and analyze orders, revenue, restaurant performance, customer spending, and geographical trends.”

⭐ A — Action

“I used SQL Server to check NULLs, blanks, and duplicates, then created a Star Schema with one fact table and dimension tables for Date, Location, Restaurant, Category, and Dish. I used JOINs, CTEs, window functions, GROUP BY, CASE statements, and aggregations to calculate KPIs and identify trends.”

⭐ R — Result

“The analysis helped identify total orders, revenue, average price and rating, top cities and restaurants, popular categories/dishes, and monthly trends, which can support business and operational decisions.”
